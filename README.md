## Project Description
This project recreates the front page of the Aurangabad Times Urdu Daily (13th March 1987) in English using HTML5. The goal was to visually resemble the original newspaper layout while following strict assignment rules, including semantic HTML structure, table-based column layout, and inline styling only. The design replicates the multi-column format, colored headline strips, and image placement to achieve approximately 70% similarity.

## Features Implemented
- Proper !DOCTYPE html and complete HTML5 document structure
- Semantic HTML5 tags (header, nav, main, section, article, footer)
- 2-column layout for top headlines using table
- 3-column newspaper-style layout for middle and bottom sections
- Colored strips (blue, black, red, pink) using inline styles
- Proper heading hierarchy (h1 to h4)
- Use of both unordered (ul) and ordered (ol) lists
- At least 8 properly mapped images with alt attributes
- Clean indentation and readable, valid HTML5 structure

## Challenges Faced
One of the main challenges was recreating the complex multi-column newspaper layout using only HTML tables without external CSS. Maintaining visual similarity while keeping the code clean, structured, and valid HTML5 required careful planning and consistent indentation.
